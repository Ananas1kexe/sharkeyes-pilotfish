# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Email **security@sharkeyes.dev** (or use GitHub's
"Report a vulnerability" button in the Security tab). We aim to acknowledge reports
within 72 hours.

## Scope and limits

PII detection is probabilistic. Pilotfish reduces the chance that personal data
reaches a third-party LLM, but it does not guarantee that every identifier is caught.
Review your threat model before using it with regulated data.
